# 🏦 Python Banking System

A simple **Banking System** built with Python for practicing basic programming concepts and Object-Oriented Programming.

## ✨ Features

* Create a bank account
* Login using account number and PIN
* Check account balance
* Deposit money
* Withdraw money 
* View transaction history 
* Logout 

## 🛠️ Concepts Practiced
 
* Python Classes & Objects
* Functions
* Dictionaries
* Loops
* Conditional Statements
* Exception Handling
* User Input & Validation

## ▶️ How to Run

Make sure Python is installed.

```bash
python banking_system.py
```

## 📌 Note

This is a **practice project** created to improve Python programming and OOP skills. It is not intended for real banking or financial use.
